# waves/

One directory per wave: `waves/<wave_id>/wave.json` (the manifest the integrator writes), and
`waves/<wave_id>/lanes/<lane_id>/` (a `BRIEF.md` generated by `wave init`, and the lane's own `report.json`).
These files live on the `wave/<wave_id>` branch and reach `main` with the wave pull request.

`TEMPLATE/` holds a manifest and a lane report to copy. The procedure is `WAVE_PROTOCOL.md`; the tool is
`cd orchestrator && python -B -m governance wave --help`.

Nothing here is a registry: ownership of paths on `main` stays in `ACTIVE_TASKS.json`, which only `wave close` updates for a wave.
